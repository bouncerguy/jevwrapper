# Contributing

Fork the repository, make a focused change, and open a pull request explaining its behavior and validation. Run `npm test` and `npm run check` with Node 22+.

Useful contributions include alternative interpreter adapters, real evaluation datasets, accessibility improvements, and small documented workflow examples. Preserve raw JEV values, label synthetic examples, and distinguish probability from confidence. Never include live credentials or private data.

Contributions are provided under the repository's MIT license. No contributor agreement is required.
